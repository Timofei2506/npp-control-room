# Заглушки Unity для офлайн-проверки

Эти файлы **не собираются Unity** (лежат вне `Assets/`) и нужны только для проверки
синтаксиса и типов без редактора: `mcs` компилирует `Assets/**/*.cs` против минимального
API `UnityEngine` / `UnityEngine.UI` / `UnityEditor`.

Запуск: `tools/checks/check.sh [wss://адрес-релея/ws]`

Ограничения: заглушки не воспроизводят физику Unity, поэтому визуальные/сценарные ошибки
эта проверка не ловит — только ошибки компиляции и типов. Поведение рантайма проверяется
в Unity; физика и сеть — в `tools/checks`.
