# БЛОК №4 — симулятор оператора АЭС (ВВЭР-1000)

[![Checks](https://github.com/Timofei2506/npp-control-room/actions/workflows/checks.yml/badge.svg)](https://github.com/Timofei2506/npp-control-room/actions/workflows/checks.yml)
[![Build Windows x64](https://github.com/Timofei2506/npp-control-room/actions/workflows/build.yml/badge.svg)](https://github.com/Timofei2506/npp-control-room/actions/workflows/build.yml)

Многопользовательский симулятор блочного щита управления энергоблоком с реактором ВВЭР-1000.
Реалистичная физика реактора и парогенератора, процедурный блочный щит с сотнями интерактивных
органов управления (тумблеры, верньеры, кнопки, стрелочные приборы, семисегментные табло,
мнемосхема, аварийная сигнализация), кооператив до 8 человек.

Собрано на **Unity** (built-in render pipeline), целевая платформа — **Windows x64**.
Мультиплеер — **Cloudflare Workers + Durable Objects** (WebSocket-релей комнат).

> **Статус:** все скрипты компилируются без ошибок (проверка против заглушек Unity),
> физика прогнана по эталонным сценариям, сеть проверена сквозным тестом против
> развёрнутого облачного релея (хост + гость, команды, снапшоты, чат, выход хоста).

> ⚠️ **Это учебный симулятор.** Он упрощён, не является тренажёром, руководством или моделью
> для реальных расчётов и не должен использоваться для подготовки персонала АЭС.

## Что внутри

| Компонент | Где | Описание |
|---|---|---|
| Физика блока | `unity/NPPControlRoom/Assets/Scripts/Sim` | точечная кинетика с запаздывающими нейтронами, температуры топлива/теплоносителя, ПГ, турбина, генератор, ксенон, защиты, инерция ротора ГЦН |
| Блочный щит | `.../Scripts/Room` | всё генерируется кодом: помещение, пульты, приборы, процедурные текстуры и карты нормалей, звук |

## Как получить игру

Сборка живёт **в GitHub Actions**, локальный Unity не нужен:

1. Один раз добавьте секреты `UNITY_EMAIL` и `UNITY_PASSWORD` от аккаунта Unity
   (файл `.ulf` для Personal не нужен — подробности в [docs/CI.md](docs/CI.md)).
2. Каждый пуш в `main` собирает exe; готовый архив — **Actions → Build Windows x64 →
   Artifacts → NPPControlRoom-Windows-x64**. По тегу `v*` создаётся релиз.
3. Распакуйте zip и запустите `NPPControlRoom.exe` (Windows x64).

## Быстрый старт в редакторе (для правок кода)

1. Установите **Unity 6 LTS** (6000.0.x) и модуль *Windows Build Support*.
2. Откройте папку `unity/NPPControlRoom` через Unity Hub («Add project from disk»).
   Скрипт `NPPBuildTools` сам создаст сцену и добавит её в Build Settings.
3. Меню **NPP ▶ Собрать Windows x64** — готовый билд появится в
   `unity/NPPControlRoom/Build/Windows/NPPControlRoom.exe`.
   (Либо просто нажмите Play в редакторе — игра запускается прямо из пустой сцены.)
4. В главном меню — **ОДИНОЧНАЯ ИГРА**.

## Мультиплеер

**Вариант А — облако Cloudflare (по умолчанию).**
Релей уже развёрнут, адрес прописан в `Assets/Resources/server.json`.
Хост: «СОЗДАТЬ КОМНАТУ» → получает 4-символьный код → сообщает друзьям.
Гости: «ПРИСОЕДИНИТЬСЯ» → вводят код.

**Вариант Б — локальный сервер (LAN, без интернета).**

```bash
cd server/node-relay
npm install
npm start            # слушает 0.0.0.0:8787
```

В игре: *Настройки → Адрес сервера* → `ws://IP-хоста:8787/ws`.

Физику всегда считает компьютер хоста; гости шлют команды, хост рассылает снапшоты 10 раз/с.

## Проверка без Unity

В репозитории есть офлайн-проверки (нужны `mono`/`mcs` и `node`):

```bash
tools/checks/check.sh wss://npp-relay.tgargach12.workers.dev/ws
```

1. компилирует все скрипты (включая Editor) против заглушек Unity — ловит ошибки типов;
2. прогоняет эталонные сценарии физики (`tools/sim-prototype/physics.js`);
3. поднимает два сетевых клиента против релея: хост + гость, команда, снапшот, чат,
   обрыв хоста, передача роли — и проверяет, что всё доходит.

Последний прогон (номинал): 3000 МВт тепловых, 990 МВт электрических, ПГ 6.0 МПа,
Tf 600 °C, уровень 50 %.

## Управление

- **WASD** — ходьба, **Shift** — бег, **мышь** — обзор, **ПКМ** — приблизить
- **ЛКМ** — нажать кнопку / переключить тумблер / открыть защитную крышку
- **колесо мыши** над верньером — изменить уставку, **ЛКМ + движение** — плавная регулировка
- **Enter** — чат, **F1** — справка, **Esc** — пауза

Ключевые органы: **АЗ-5** (аварийная защита под красной крышкой), **СТЕРЖНИ** (глубина
погружения), **ГЦН-1..3**, **КЛАПАН ТУРБИНЫ**, **ГЕНЕРАТОР**, **ПИТАТ. НАСОСЫ / АВТО УРОВНЯ**,
**БРУ-А**, квитирование сигнализации.

## Физика (кратко)

- 6-групповая модель запаздывающих нейтронов (β=0.0065, Λ=20 мкс)
- Отрицательные обратные связи: доплер по топливу, температурный коэффициент теплоносителя
- Инерция тепловыделения, остаточное тепло после останова
- Парогенератор: давление, уровень, питание, предохранительные клапаны, БРУ-А
- Турбина: клапан, мощность, критические обороты (защита от разгона), генератор и сеть
- Ксеноновое отравление (ускорено в 600 раз для играбельности)
- Автоматические защиты: мощность >115 %, давление пара >8.5 МПа, температура топлива
  >1000 °C, расход ГЦН < 2 насосов, уровень ПГ < 15 % → останов турбины

Модель откалибрована скриптом `tools/sim-prototype/physics.js`; подробности — `docs/ARCHITECTURE.md`.
