# Безопасность и секреты

## Правила

1. **Никаких токенов в репозитории.** `.private/`, `.env`, `*.ulf`, ключи R2 — только локально
   (все они в `.gitignore`).
2. Токены Cloudflare и GitHub выданы владельцем проекта; используйте минимально необходимые
   права и срок жизни.
3. Код комнаты — не пароль: подбор кода возможен, не проводите «закрытые» турниры на публичном релее.

## Что было передано в чат

При постановке задачи в открытый чат были переданы:

- GitHub PAT (`ghp_…`) со широкими правами;
- Cloudflare API Token (`cfat_…`) — активен;
- R2 Access Key / Secret (S3-совместимые).

**Все три необходимо перевыпустить** после настройки проекта:

### GitHub

1. <https://github.com/settings/tokens> → удалить старый токен → **Generate new token (classic)**
   с правами `repo`, `workflow` (или fine-grained только на этот репозиторий).
2. Новый токен никому не пересылать; для git использовать credential manager/SSH-ключ.

### Cloudflare API Token

1. Dashboard → My Profile → API Tokens → **Roll** или удалить `cfat_…` и создать новый:
   - *Workers Scripts:Edit*, *Durable Objects:Edit*, *Account Settings:Read*;
   - при необходимости R2: *Workers R2 Storage:Edit*.
2. Обновить `CLOUDFLARE_API_TOKEN` в своём окружении.

### R2

> Релею R2 не нужен: он только пересылает сообщения и ничего не хранит. Ключи можно
> отозвать целиком, если не планируется хранить сборки/логи в облаке.

1. R2 → Manage R2 API Tokens → удалить ключ `ef18…` → создать новый (Object Read & Write
   на конкретный бакет), только если понадобится хранение.
2. Секретный ключ показывается один раз — сохранить в менеджере секретов.

## Релей

- Воркер не хранит данных и не требует аккаунтов; сообщения валидируются по длине и алфавиту.
- Тексты чата очищаются от `<>&` (защита от rich-text-инъекций в HUD).
- Имена и сообщения ограничены 16/200 символами, команды — 8 игроков на комнату.
- При необходимости ограничьте доступ WAF-правилами или Cloudflare Access.
- Node-релей не имеет аутентификации и шифрования: используйте только в доверенной LAN
  либо за reverse-proxy с TLS.

## Если токен утёк

1. Немедленно отозвать (GitHub/Cloudflare → API Tokens → Revoke).
2. Проверить журналы: GitHub → Settings → Security log; Cloudflare → Audit log.
3. Перевыпустить и обновить конфигурацию.
