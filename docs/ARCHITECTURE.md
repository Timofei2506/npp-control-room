# Архитектура

## Слои

```
UI (NPP.UI)      меню, HUD, чат, тревоги
      │
Core (NPP.Core)  GameManager — режимы, сетевой цикл, квитирование
      │
Sim (NPP.Sim)    PlantSimulation — физика; PlantSnapshot — единый снимок состояния
      │
Net (NPP.Net)    NetworkSession → RelayClient (ClientWebSocket) → Cloudflare/Node relay
Room (NPP.Room)  процедурный блочный щит; элементы читают GameManager.Latest
```

Единый источник правды для интерфейса — `PlantSnapshot` (структура из ~23 полей). Приборы
каждый кадр читают `GameManager.Instance.Latest` — им не важно, локальная это физика или
сетевой гость.

## Физическая модель (`PlantSimulation.cs`)

Шаг модельного времени фиксирован: **50 мс**, до 8 подшагов за кадр (защита от «спирали смерти»).
Внутри шага кинетика решается с подшагами по 5 мс.

### Реактивность

```
ρ = ρ_rod + ρ_doppler + ρ_coolant + ρ_xenon
ρ_rod     = 0.035 · (0.62 − rod)        стержни: 3.5 % полного хода, рабочая точка 62 %
ρ_doppler = −1.5·10⁻⁵ · (Tf − 600)
ρ_coolant = −2.5·10⁻⁵ · (Tc − 290)
ρ_xenon   = −0.004 · (Xe − 1)
```

### Кинетика (одногрупповое приближение, интегрируется неявно)

```
dP/dt = (ρ − β)/Λ · P + λ·C
dC/dt = β/Λ · P − λ·C
β = 0.0065, Λ = 2·10⁻⁵ c, λ = 0.0784 c⁻¹
```

При ρ > 0 может возникнуть «мгновенный» разгон; шаг по мощности неявный, поэтому
интегрирование устойчиво при любой реактивности. Мощность ограничена 300 % (численный
потолок); повреждение активной зоны фиксируется при Tf > 1000 °C или P > 150 %
(латч, требует сброса модели). Защита от превышения 115 % срабатывает *внутри* подшагов.

### Теплофизика

```
Q_heat = 3000 МВт · (0.93·P + Q_decay)
Q_fc   = (0.2 + 9.477·n_ГЦН/3) · (Tf − Tc)   // 0.2 — естественная циркуляция
dTf/dt = (Q_heat − Q_fc)/60
dTc/dt = (Q_fc − Q_cs)/250
Q_cs   = 100·max(0.06, n/3) · (Tc − (170 + 15·P_пг))
```

### Парогенератор и турбина

```
Q_турб = 555.56 · P_пг · клапан (0 при трипе турбины)
Q_сброс = БРУ-А (если открыт) + предохранительные клапаны P_пг > 7.8 МПа
dP_пг/dt = (Q_cs − Q_турб − Q_сброс)/400
dLvl/dt  = 1.2 · (питание − Q_турб/2820)
```

Турбина: при включённом генераторе обороты синхронизируются с сетью (3000 об/мин);
при отключённом — разгон `dW/dt = (120·P_пг·клапан − 0.024·W)/6`, защита при 3150 об/мин.
Мощность генератора ≈ 0.33·Q_турб (КПД 33 %).

### Автоматика

| Условие | Действие |
|---|---|
| P > 115 % | АЗ (SCRAM) |
| Tf > 1000 °C | АЗ |
| P_пг > 8.5 МПа | АЗ |
| ГЦН < 2 | АЗ |
| Lvl < 15 % | останов турбины |
| W > 3150 | останов турбины |
| АЗ активна | стержни вводятся со скоростью 40 %/с, турбина останавливается |

Ксенон: `I' = (P − I)/600`, `Xe' = (0.9·I + 0.1·P − Xe·(0.1 + 0.9·P))/600` — ускорено
для играбельности; «ксеноновая яма» после сброса реальна и мешает повторному пуску.

## Блочный щит

Всё строится процедурно (`ControlRoomBuilder`, `PanelFactory`), внешних моделей и текстур нет:

- текстуры приборов и экранов рисуются в `PixelCanvas` (свой пиксельный 5×7 шрифт и семисегментные цифры);
- материалы создаются из трёх самописных шейдеров (`Assets/Resources/Shaders/NPP*.shader`);
- звуки синтезируются в рантайме (`SoundBank`: клики, гул, сирена);
- шрифты Unity UI/TextMesh — DejaVu Sans и DejaVu Sans Mono (включены в проект).

Элементы щита: `AnalogGauge`, `DigitalReadout`, `ToggleLever`, `PumpSwitch`, `RotaryKnob`,
`PushButton`, `FlipCover`, `ScramButton`, `IndicatorLamp`, `AlarmTile`, `AckButton`,
`MimicScreen`, `ClockDisplay`, `LevelBar`, `AlarmBeacon`, `EmergencyLight`.

Взаимодействие: `FirstPersonPlayer` бросает луч из центра камеры (2.7 м) и находит
`IInteractable` в родителях коллайдера. Интерфейс: `Hint()`, `Click()`, `Scroll(d)`, `Drag(delta)`.

## Сетевой протокол

WebSocket, текстовые JSON-сообщения. Код комнаты — 4–6 символов `A-Z0-9`.

| Направление | Сообщение |
|---|---|
| C→S | `{"t":"join","name":"Имя"}` |
| S→C | `{"t":"joined","id":"…","role":"host|guest","room":"K7Q2","peers":[…]}` |
| S→C | `{"t":"peers","peers":[{"id","name","role"}]}` |
| C→S | `{"t":"cmd","id":3,"value":0.55}` |
| S→C (хосту) | `{"t":"cmd","id":3,"value":0.55,"from":"peerId"}` |
| S→C (гостям) | `{"t":"state","state":"{\"p\":1.0,…}"}` — 10 Гц |
| C→S / S→C | `{"t":"chat","text":"…"}` / `{"t":"chat","name":"…","text":"…"}` |
| C→S | `{"t":"ping","ts":…}` → `{"t":"pong","ts":…}` (RTT в HUD) |
| S→C | `{"t":"host_left"}` — хост ушёл, комната закрывается |

Хост-авторитет: только хост применяет команды к `PlantSimulation` и рассылает снапшоты;
выход хоста закрывает сессию (состояние реактора не мигрирует).

Снапшот кодируется компактным словарём (`SnapshotCodec`): `p, rod, rt, pm, pmsk, vl, fd, fa,
br, vt, tf, tc, ps, lv, rpm, pel, xe, rho, rad, al, scr, tt, cd, t`.

Идентификаторы команд — `ControlId`: `RodTarget=1, Pumps=2 (битовая маска 0..7), Valve=3,
Feed=4, FeedAuto=5, Breaker=6, Vent=7, Scram=8, Reset=9`.

Идентификаторы тревог — биты `AlarmBits` (15 шт.), передаются одним int.

## Производительность

- кинетика/теплофизика — доли микросекунды на шаг;
- текстуры генерируются один раз при сборке щита;
- `DigitalReadout` перерисовывает текстуру только при изменении строки (каждые 0.12 с проверка);
- мнемосхема — 4 кадра/с;
- освещение: 6 потолочных светильников + 2 лампы пультов + направленный свет; тени только
  у трёх источников.

## Известные упрощения

- одна «схлопнутая» группа запаздывающих нейтронов вместо шести;
- нет модели давления 1-го контура и протечек;
- ксенон ускорен;
- пар/вода без гидравлики, только энергобаланс;
- режим пуска с нуля отсутствует: модель стартует на 100 % мощности (сброс — это «перезапуск сценария»).
