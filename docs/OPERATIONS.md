# Эксплуатация блока (учебные сценарии)

> Все процедуры — игровые. Не использовать на реальных объектах.

## Начальное состояние

При входе в игру блок работает на **100 % номинала**: мощность 3000 МВт (электрическая ~990 МВт),
стержни на 62 %, все три ГЦН включены, клапан турбины 90 %, авторегулирование уровня включено,
генератор в сети.

## Роли в экипаже (кооператив)

| Роль | Зона | Задачи |
|---|---|---|
| ВИУР (начальник смены) | центр зала | общее руководство, квитирование сигнализации, координация |
| РО (реактор) | левый пульт | стержни, ГЦН, БРУ-А, АЗ-5 |
| ТО (турбина) | правый пульт | клапан, питание, генератор |

## Нормальная работа

1. **Мощность** задаётся ручкой **СТЕРЖНИ** (0 % — полностью извлечены, 100 % — введены).
   Движение стержней медленное (~25 с на полный ход) — это нормально.
2. Следите за **ТОПЛИВО** (600 °C на номинале) и **ТЕПЛОНОСИТЕЛЬ** (290 °C).
3. **Уровень в ПГ** должен держаться около 50 % — включён «АВТО УРОВНЯ».
4. **ОБОРОТЫ** — 3000 об/мин, **МОЩНОСТЬ** ~990 МВт, **ДАВЛЕНИЕ ПАРА** ~6 МПа.

### Снижение мощности

- Медленно вводите стержни (задание +5…10 % за раз), пауза 20–30 с.
- Ксенон после снижения мощности сначала «разгоняет» реактор (йодная яма наоборот),
  затем добавляет отрицательную реактивность — не гоните стержни вслепую, смотрите на
  реактивность и мощность.

## Аварийные сценарии для тренировки

### 1. SCRAM (аварийная защита)

1. Открыть крышку **АЗ-5**, нажать красный гриб.
2. Стержни входят автоматически; турбина отключается, генератор сбрасывается.
3. Нейтронная мощность падает до нуля, но остаточное тепловыделение ~7 % (210 МВт) —
   в приборе «МОЩНОСТЬ» оно и отображается, медленно снижаясь в течение часов.
4. Следите за уровнем ПГ (питание продолжает работать) и давлением (растёт — возможен
   сброс через предохранительные клапаны; можно приоткрыть **БРУ-А**).
5. Возврат к работе: **СБРОС МОДЕЛИ** (кнопка под синей крышкой на панели КИП или в паузе).

### 2. Потеря питания насосов (Fukushima-подобный)

- Выключить два из трёх ГЦН → мгновенная АЗ по низкому расходу.
- Выключить все три → АЗ срабатывает сразу. Насосы не встают мгновенно: ротор выбегает
  ~4 с, поэтому расход падает плавно. Дальше остаточное тепло отводить нечем: топливо
  разогревается до 1000 °C примерно за 3–4 минуты → повреждение активной зоны,
  красный баннер, радиация, сирена.
- Учебная цель: успеть восстановить насосы **до** 1000 °C.
- Сигнал «НИЗКИЙ РАСХОД» загорается по фактическому расходу (ниже 60 %), а не по
  положению выключателей — после отключения двух ГЦН он появится через пару секунд.

### 3. Разгон турбины

- При отключённом генераторе полностью открыть **КЛАПАН** → обороты растут →
  защита от разгона при 3150 об/мин останавливает турбину.

### 4. Потеря питания парогенератора

- Отключить **АВТО УРОВНЯ**, убрать питание до нуля → уровень падает →
  при <30 % предупреждение, при <15 % останов турбины, затем АЗ по давлению/уровню.

### 5. Разгон реактора стержнями

- Извлечь стержни до 10–20 % → положительная реактивность → мощность растёт → АЗ по 115 %.
- При очень быстром извлечении возможен «мгновенный» разгон и повреждение зоны.

## Квитирование

Красные табло мигают, пока авария активна и не квитирована. Кнопка **КВИТ** на табло
выключает сирену; сами табло остаются до исчезновения условия. При новом срабатывании
сигнализация включается снова.

## Частые ошибки новичков

- Крутить стержни «до упора» без наблюдения за реактивностью → разгон/останов.
- Забыть про ксенон после снижения мощности → «провал» мощности на 10–20 минут.
- Оставлять генератор включённым при остановленной турбине — выработка падает сама, но
  при отключённом генераторе турбина без клапана может разгоняться.
- Квитировать тревогу и думать, что авария устранена — табло лишь замолкает.
